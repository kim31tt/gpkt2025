# tabi

Responsive Linktree-style travel profile.

## Layout

- Smartphone: single-column layout
- Tablet: wider single-column layout
- PC: two-column layout with profile on the left and visited countries on the right

## Upload to GitHub

Upload these files into the `tabi` folder.

```txt
index.html
style.css
script.js
assets/
  icon.jpg
  background.jpg
```
