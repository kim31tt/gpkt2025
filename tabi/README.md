# Kimie Travel Profile

シンプル版のプロフィールページです。

## Instagramリンクの変え方

`index.html` のこの部分を自分のInstagram IDに変更してください。

```html
https://www.instagram.com/YOUR_INSTAGRAM_ID/
```

例：

```html
https://www.instagram.com/kimie_travel/
```

## 写真の差し替え方

`assets` フォルダにプロフィール写真を入れて、ファイル名を `profile.jpg` にした場合は、`index.html` の以下を変更します。

```html
assets/profile-placeholder.svg
```

↓

```html
assets/profile.jpg
```
